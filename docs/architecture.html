4Rules that never break

Each one is backed by the design and by the tests in tests/unit.

No e-mail is ever sent

Only drafts are created with POST /me/messages; there is no call to /send anywhere. The person reviews and sends.

No credential touches the disk

Password, Microsoft token, GitLab and Azure cookies live in the Session; git gets the password through environment variables only. The browser uses only sessionStorage.

Every user is isolated

Browser contexts, HTTP client, temp folder, generated files and builds are per session. Nobody sees another person's work.

Nothing is guessed

A task belongs to a requirement only if it is the story or its parent is; only commits naming the GEIR's stories are compiled.

The Excel keeps its format

Edited at XML level: in-cell images, merges, validations and styles stay. New rows copy the first row's format.

A failure never loses the document

The original goes to the OneDrive recycle bin only after the copy is modified; a failed upload keeps the copy.

Quality: npm run typecheck · npm test (32 unit tests) · .gitlab-ci.yml: verify → test → package → publish
Deployment: npm run build + npm run package → release/geir-<version>.zip · Linux: deploy/geir.service + deploy/nginx-geir.conf (HTTPS) · Windows: iniciar-geir.cmd
